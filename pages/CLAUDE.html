jitmodel

Model and web app for the re-condensing cryogenic power cycle of US 11,598,261 (Just In Time Energy). The full plan is in PLAN.md. The patent is docs/US11598261.pdf. Decisions are logged in docs/DECISIONS.md and validation results in docs/VALIDATION.md (including how to read the dispatch comparison). The Cloud Run deployment is documented in docs/DEPLOY.md.

Working rules

  1. Work one phase at a time, in order. Don’t start a phase until the previous phase’s acceptance checks pass.
  2. Run the tests after every meaningful change (make test, which runs .venv/bin/pytest). Commit at the end of each phase with a message like phase 3: discretized HX + pinch solver.
  3. Never invent performance numbers. Anything not computed by the solver or taken from the patent shows — in the UI. Test fixtures may use patent values only, each with a comment citing the figure or column.
  4. Units: use SI internally (Pa, K, J/kg, kg/s, W). Convert to US customary (psia, °F, Btu/lb, lb/h, MW) only at the UI boundary, through one jitmodel/units.py module. Include a UI toggle for SI vs. US customary.
  5. Dependencies: use only those listed in PLAN.md §2. Ask before adding anything else.
  6. Record non-obvious modeling choices in docs/DECISIONS.md, one short entry per decision.
  7. Nothing outside the repo. Never run installer scripts, sudo, global pip/npm installs, or anything that edits files outside this directory (shell profiles, ~/.local, ~/.config). If a system package is needed, ask the user to apt install it.
  8. Vet every Python package before downloading it (typosquatting). Before adding or installing any package, including a new transitive dependency, check its PyPI page (https://pypi.org/pypi/<name>/json):
    • the exact spelling of the name,
    • that its source repo belongs to the expected project or organization,
    • its first-release date and release history,
    • which package requires it (pip show <name>, Required-by). Report the findings to the user. Never pip install jitmodel by name: it’s this local package, installed only with pip install -e ..

Stack (see PLAN.md §2)

  • Python 3.13 (Debian) in .venv (make setup). Flask + Jinja + plain HTML/CSS + small vanilla JS modules. No Node/npm, bundler or client-side framework.
  • Charts: Plotly.js, vendored in jitmodel/web/static/vendor/. No CDN at runtime.

Commands

  • make setup: create .venv, install .[dev], enable .githooks
  • make dev: dev server at http://0.0.0.0:5001 (dev only, no auth)
  • make test: pytest (excludes tests/e2e)
  • make e2e: Playwright smoke test against /usr/bin/chromium
  • make lint: ruff check, ruff format –check, mypy –strict on jitmodel/core
  • make validation: re-solve every preset and regenerate the summary in docs/VALIDATION.md
